# mini-yahtzee

Requires [Bun](https://bun.sh) (or another typescript runtime) to run.

## Usage

```bash
# Run with multiset approach (default, faster)
bun run index.ts

# Run with colored dice approach
bun run index.ts --c

# Force recomputation of policies
bun run index.ts --recompute
```
